Perguntas Frequentes

Tudo o que você precisa saber.

Como o Stealth Mode funciona de verdade?

O Refract usa setContentProtection no nível do sistema operacional. A janela do overlay é marcada como conteúdo protegido — o compositor do SO a exclui de qualquer captura de tela ou compartilhamento (Zoom, Meet, Teams, Discord), enquanto ela continua visível para você.

Ele é detectado pelo Zoom / Teams / Meet?

Não. O Refract não injeta código em outros processos nem usa hooks detectáveis — é apenas uma janela protegida pelo SO com captura de áudio via APIs nativas (CoreAudio / WASAPI). Não há driver, DLL injetada ou overlay de jogo para ser sinalizado.

Preciso de internet para usar?

Depende do modo. Com Ollama + Whisper local, tudo roda 100% offline. Com provedores de nuvem (Claude, GPT-4o, Gemini), você precisa de internet apenas para as chamadas de API — o áudio e a tela nunca passam por nossos servidores.

Meu áudio é gravado ou enviado para algum servidor?

Não. A transcrição acontece em streaming direto para o provedor de STT que você escolheu (ou localmente, com Whisper). O Refract não mantém servidor intermediário, não grava arquivos de áudio e tem telemetria zero por padrão.

Quanto custa? Preciso de assinatura?

O Refract é source-available e usa o modelo Bring Your Own Key: você paga apenas os tokens de custo bruto ao provedor que escolher. Sem mensalidade cara, sem markup sobre seus tokens.

Quais plataformas são suportadas?

macOS 12+ (Apple Silicon e Intel) e Windows 10/11. Binários assinados, com auto-update via GitHub Releases.
